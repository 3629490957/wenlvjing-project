# 文旅境——沉浸式旅游开发平台

本项目为软件工程Web课程大作业，独立主导开发，采用纯原生 HTML5 / CSS3 / JavaScript 构建，无任何第三方框架依赖。

## ✨ 核心功能
- 8大景点数据动态渲染与多页无刷新切换
- 5图自动轮播与手动切换防冲突（定时器重置）
- 景点分类筛选与详情弹窗
- 表单正则验证与点赞缩放动画
- 移动端响应式布局（含汉堡菜单）

## 🛠️ 遇到的问题与解决
- **图片路径404**：理清了 JS 与 CSS 相对路径的区别，将 JS 内路径统一修改为相对入口 HTML 定位。
- **轮播图冲突**：使用 `clearInterval` 在手动切换时重置定时器，解决自动播放冲突。
